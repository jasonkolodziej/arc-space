## Daily workflow

1. **Arc: Open Arc Workspace**: login-node window for editing, submitting and transfers.
2. **Allocate** a node (Jobs view ▶ or a partition's ▶). Prefer CPU partitions for development; GPU jobs idle over 1 h are killed.
3. Click the status bar **Arc node … ready** → the same workspace opens on the compute node.
4. **Release** the node when you're done.

Run Task → **arc** lists the built-in tasks.
